STRATEGY CLASSIFICATION DECISION TREE
================================================================================

Location: Lines 2428-2461 (inside mainCalculate)

Order of checks:
  1. Direct Path        (ipe <= 125 AND heading <= 40)
  2. Focal Search       (distance to centroid + distance to goal)
  3. Directed Search    (corridor >= 70% AND ipe <= 1500)
  4. Indirect Search    (ipe < 300 AND heading < 70)
  5. Semi-focal Search  (looser focal criteria)
  6. Chaining           (annulus >= 90% AND quadrants >= 4)
  7. Scanning           (traversed 5-20% AND near center)
  8. Thigmotaxis        (thigmo zones AND distance > 400)
  9. Random Search      (traversed >= 10%)
  10. Not Recognized    (else)

This logic is PURE and should be extracted to classify_strategy() in analysis.py
