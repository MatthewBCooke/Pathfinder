7. STRATEGY CLASSIFICATION LOGIC (Lines 2428-2461)
================================================================================

This decision tree is PURE and ready to extract:

IF ipe <= 125 AND heading <= 40                     => Direct Path (score=3)
ELIF focal conditions met                            => Focal Search (score=2)
ELIF corridor >= 70% AND ipe <= 1500                => Directed Search (score=2)
ELIF ipe < 300 AND heading < 70                     => Indirect Search (score=2)
ELIF semi-focal conditions met                       => Semi-focal Search (score=2)
ELIF annulus >= 90% AND quadrants >= 4              => Chaining (score=1)
ELIF traversed 5-20% AND near center                => Scanning (score=1)
ELIF thigmo zones met AND distance > 400            => Thigmotaxis (score=0)
ELIF traversed >= 10%                                => Random Search (score=0)
ELSE                                                  => Not Recognized
