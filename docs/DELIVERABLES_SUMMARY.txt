================================================================================

   - Tries: AnyMaze → WaterMaze → Ethovision → Basic CSV
   - Clear error messages showing tried formats
   - Pandas optional (only for Excel)

   - Loading runs in QThread (GUI responsive)

   - File not found → Clear message
   - Invalid format → Shows tried formats
   - Analysis failure → Exception details
   - Missing dependencies → Install instructions
